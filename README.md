# 🚀 LearnAI.NET

> A Complete AI Engineering Platform Built with .NET

LearnAI.NET is a comprehensive AI engineering solution designed to help .NET developers master modern AI application development from fundamentals to enterprise-scale AI systems.

This repository demonstrates the complete AI engineering lifecycle using:

- ASP.NET Core MVC
- ASP.NET Core Web API
- Microsoft.Extensions.AI
- Semantic Kernel
- Retrieval-Augmented Generation (RAG)
- Agentic AI
- Model Context Protocol (MCP)
- Azure AI Services
- AI Evaluation & Testing

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/farhan1386/LearnAI-MVC.git
```

## Navigate

```bash
cd LearnAI-MVC
```

## Restore Packages

```bash
dotnet restore
```

## Build Solution

```bash
dotnet build
```

## Run API

```bash
dotnet run --project LearnAI.API
```

## Run MVC Application

```bash
dotnet run --project LearnAI.Web
```

## Run React Application

```bash
cd LearnAI.React
npm install
npm start
```
